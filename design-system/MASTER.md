# Straightline master

The ui-ux-pro-max search script was not on this machine, so this file records the system that was actually built.

## Pattern

Asymmetric first screen, then a four-cover index, a four-step placement sequence, a horizontal year, one claim quote, an insurer list, questions, and a callback.

## Color

| Role | Token | Value |
| --- | --- | --- |
| Pine | `--pine` | `oklch(0.33 0.052 158)` |
| Paper | `--background` | `oklch(0.975 0.006 155)` |
| Ink | `--foreground` | `oklch(0.25 0.03 158)` |
| Muted ink | `--muted-foreground` | `oklch(0.38 0.03 158)` |
| Persimmon | `--primary` | `oklch(0.50 0.145 38)` |

Body text and muted text both clear 4.5:1 on paper. Persimmon buttons clear 4.5:1 in light and dark.

## Avoid

Navy-and-gold insurance chrome, warm cream pages, purple glow, equal three-card rows, gradient headlines, eyebrows on every section, em dashes.

## Stack

Next.js, Tailwind, shadcn/ui (Base UI), Phosphor icons, GSAP for the year pin, Motion for cover entrances.
